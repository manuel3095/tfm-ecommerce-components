=== TFM Tienda de prueba ===
Requires Plugins: woocommerce
Stable tag: 1.0.0
License: GPL-2.0-or-later

Crea la tienda de demostración que usan las pruebas de usabilidad (SUS) y la auditoría Lighthouse del plugin TFM Ecommerce Components.

== Uso ==

1. Active WooCommerce y TFM Ecommerce Components.
2. Instale y active este plugin.
3. Vaya a Herramientas → TFM: tienda de prueba y pulse «Crear la tienda de prueba».
4. Al terminar las pruebas, pulse «Eliminar los datos de prueba» para dejar la tienda como estaba.

WP-CLI: wp tfm-tienda crear | wp tfm-tienda eliminar
